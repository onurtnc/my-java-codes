# Student Grade Management System (Java)

This project is a **console-based Student Grade Management System** developed in **Java**.  
It allows managing students, courses, grades, and generating detailed academic reports with class-level statistics.

## 🚀 Features
- 👤 Add new students
- 📝 Add course grades (midterm, final, assignment)
- 📊 Automatic grade average calculation
- 🔤 Letter grade determination (AA–FF)
- ✔️ Pass / Fail status evaluation
- 📋 Student list with overall averages
- 📑 Detailed student report (transcript-like view)
- 🔍 Search students by name or surname
- 🏆 Top-performing students ranking
- 📈 Class statistics (average, highest, lowest)

## 🛠 Technologies Used
- Java SE
- `Scanner` for user input
- `ArrayList` for data storage
- Object-Oriented Programming (OOP)

## How to Run
```bash
javac StudentGradeManagementSystem.java
java StudentGradeManagementSystem
```
